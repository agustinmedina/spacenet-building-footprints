# Cómo subir esta carpeta a GitHub

1. Extraé `spacenet_github_ready.zip`.
2. Abrí la carpeta extraída `spacenet-building-footprints`.
3. Creá un repositorio en GitHub; nombre sugerido: `spacenet-building-footprints`.
4. Usá **Add file → Upload files** (o **uploading an existing file** si está vacío).
5. Arrastrá el contenido de la carpeta: `README.md`, `scripts`, `notebooks`,
   `portfolio`, `results`, `data`, `docs`, `environment.yml`, `DATA_ATTRIBUTION.md`
   y `.gitignore`. Revisá que `.gitignore` esté incluido.
6. Confirmá la carga. El README debe aparecer en la portada del repositorio.

Subí el contenido descomprimido, no el ZIP ni una carpeta adicional que deje
el README un nivel por debajo de la raíz. Todos los archivos del paquete están
por debajo de 25 MiB. No contiene datasets completos, paquetes Python ni pesos.

La carga y publicación quedan a tu cargo; este paquete no creó un repositorio.
La atribución de datos está incluida. No se asignó una licencia al código.

Instrucciones oficiales:
https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
