# Data attribution

Source: SpaceNet 2 Building Detection, AOI 2 Las Vegas, SpaceNet Partners.
Dataset: https://spacenet.ai/spacenet-buildings-dataset-v2/
License: Creative Commons Attribution-ShareAlike 4.0 International.
License text: https://creativecommons.org/licenses/by-sa/4.0/legalcode

Citation: Van Etten, A., Lindenbaum, D., & Bacastow, T.M. (2018).
SpaceNet: A Remote Sensing Dataset and Challenge Series. arXiv:1807.01232.

The included satellite images originate from that dataset. COCO label masks,
predicted building polygons and visual overlays are derivatives prepared in this
project. Modifications include RGB percentile normalization, rasterization of
labels, model inference, mask vectorization and figure layout.

Keep the source attribution with redistributed data and derivative figures.
Predictions are not authoritative mapping and imply no endorsement by SpaceNet.
This file describes data attribution; it does not grant a software license.
